# Naming Conventions

## Work slugs

- Use lowercase kebab-case.
- Slugs are stable identifiers and should not change after first release.

## Manuscript files

- File name should match slug.
- Example: works/one-cell-rural/manuscript/one-cell-rural.md

## Tags

- Format: <work-slug>-vX.Y.Z
- Example: one-cell-rural-v1.2.0
